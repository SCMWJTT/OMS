# standards/

ONE's own standards: how ONE content, visuals and data are made. Each standard has its own folder so it can grow without disturbing the others.

| Folder | Standard | Status |
|---|---|---|
| `templates/` | Word master template for controlled documents (`ONE_ACE_Master_Template_v5.dotx`) | In use |
| `icons/` | **ONE Icon Standard** and the icon registry (`one-icons.json`) used by every diagram and chart | v1.0 |
| `process-data/` | **ONE Process Data Requirement**: the records ONE needs about a process to draw and measure it | v1.0 |

Room to extend, one folder each: `diagrams/` (layout and drawing rules for maps), `charts/` (chart types and colour use), `colour/` (if the colour rules outgrow the icon standard).

The document publishing rules stay in `protocol/` (ONE Document Standard and its engine).
